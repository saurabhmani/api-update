# Strategy Version Approval Report (Phase 7)

Generated by `evaluateStrategyVersionApproval`.

## Rules

1. Headline metrics must be **OOS-only** (never IS).
2. **Win rate alone cannot approve.**
3. Every frozen IS artefact must be listed (hash + window).
4. Fail → auto `Restricted` when robustness or leakage fails (elite publication blocked).

## Elite 78% reporting

When citing the aspirational elite precision target:

| Field | Required |
|-------|----------|
| Hit rate | yes |
| Sample size | yes |
| CI low / high | yes |

Omit the 78% claim if n or CI is missing.

## Reproduce

```ts
import {
  runWalkForward,
  evaluateStrategyVersionApproval,
  runRobustnessSuite,
} from '@/lib/backtesting';

const wf = await runWalkForward({ /* ... */ });
const approval = evaluateStrategyVersionApproval({
  strategy: 'fibonacci_pullback',
  strategyVersion: '2.0.0',
  oosExpectancyR: wf.headline.aggregateOosExpectancyR,
  oosProfitFactor: wf.headline.aggregateOosProfitFactor,
  // ...
  robustness: wf.robustness!,
  leakageAudit: wf.leakageAudit,
  frozenConfigs: wf.frozenArtifacts,
  reproducibility: {
    codeVersion: wf.reproducibility.parityContract,
    configVersion: wf.reproducibility.runtimeConfigVersion,
    dataVersion: wf.reproducibility.walkForward,
  },
});
```
