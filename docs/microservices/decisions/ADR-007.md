# ADR-007: Asynchronous messaging

## Status

Proposed

## Context

No durable broker is currently required.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.

## Decision

Retain MySQL queues until a real durable event case; compare Streams/RabbitMQ/Kafka/managed queues then.

## Alternatives considered

Kafka by default; in-process eventbus treated durable.

## Consequences

Lower operational burden.

## Risks

Polling limitations.

## Rollback strategy

Continue queue polling.

## Approval required

Broker choice requires approval.
