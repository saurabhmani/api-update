# ADR-005: Service authentication

## Status

Proposed

## Context

Internal services must preserve user and worker authorization.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.

## Decision

Use authenticated service identity; BFF validates sessions and forwards minimal signed identity context.

## Alternatives considered

Forward cookies blindly; unauthenticated private network.

## Consequences

Clear security boundary.

## Risks

Credential rotation/authorization design.

## Rollback strategy

Keep calls in-process.

## Approval required

Security approval required.
