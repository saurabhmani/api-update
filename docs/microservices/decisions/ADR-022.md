# ADR-022: Private-by-default Backtest resources

- Status: Proposed
- Policy approval: user-approved for implementation

Backtest resources are scoped by `backtest_runs.created_by`. Normal users access only their own runs; administrators use an explicit audited scope and may access ownerless legacy rows. Child routes authorize the parent before loading artifacts. Terminal hard deletion is owner/admin scoped and transactional; active work cannot be deleted. Workers continue using processor identity and leases.
