# ADR-014: Next.js BFF role

## Status

Proposed

## Context

Current public routes and cookie sessions terminate in Next.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.

## Decision

Gradually retain UI/auth/BFF and delegate typed internal capabilities while preserving URLs/shapes.

## Alternatives considered

Expose services to browser; immediate gateway rewrite.

## Consequences

Stable clients/security.

## Risks

Composition latency.

## Rollback strategy

Use local handlers.

## Approval required

Approve each route migration.
