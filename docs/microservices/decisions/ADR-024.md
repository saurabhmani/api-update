# ADR-024: Database-backed Backtest ownership epochs

Status: Proposed

Use the additive MySQL singleton `backtest_processor_ownership` as staging/integration ownership authority. Every transition is compare-and-set, increments a monotonic epoch, records operator and timestamp, and requires `disabled` between processing owners. Service claims and acknowledgements bind the epoch. Production application requires separate approval.

Both processor types treat environment configuration as local intent and MySQL as runtime authority. Claim and lifecycle SQL joins the singleton owner and epoch so transitions serialize with queue mutation. Entering `disabled` immediately prevents claims and rejects old-epoch finalization. Leaving `disabled` is rejected while any old-epoch `running` or `cancel_requested` lease remains; operators must allow graceful lease expiry and run stale recovery without resetting attempts. Status remains Proposed.
