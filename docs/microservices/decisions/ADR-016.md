# ADR-016: PostgreSQL usage during service extraction

## Status

Proposed

## Context

Postgres tooling is partial; MySQL is authoritative.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.

## Decision

Keep MySQL authoritative; use Postgres only for already-supported/approved ownership; separate engine cutover.

## Alternatives considered

Combined extraction and DB migration.

## Consequences

Smaller blast radius.

## Risks

Temporary heterogeneous access.

## Rollback strategy

Disable optional PG paths.

## Approval required

Database cutover approval.
