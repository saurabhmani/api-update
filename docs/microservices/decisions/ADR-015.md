# ADR-015: Transitional deployment model

## Status

Proposed

## Context

Committed production uses VPS Nginx/PM2/server.js.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.
No PM2, Nginx, Compose, Docker, port, or runtime entry configuration is changed by the prepared skeleton.

## Decision

Prefer PM2 monolith plus PM2 service initially; no current topology change.

## Alternatives considered

Kubernetes; Compose as production truth.

## Consequences

Matches operations.

## Risks

Multiple PM2 units.

## Rollback strategy

Do not start service.

## Approval required

Production topology approval.

Milestone note: local/staging instructions use the existing MySQL authority and a disabled-by-default executable. Production deployment remains approval-gated and Proposed.
