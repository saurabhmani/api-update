# ADR-012: Signal Engine extraction criteria

## Status

Proposed

## Context

Signal phases include authoritative Phase 3 and scheduled lifecycle.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.

## Decision

Extract only after Strategy/Risk/Market contracts, table/scheduler ownership, parity, shadowing, and rollback proof.

## Alternatives considered

Split phases; extract scaffold now.

## Consequences

Protects financial invariant.

## Risks

Delayed scaling benefit.

## Rollback strategy

Remain monolith.

## Approval required

Explicit readiness review.
