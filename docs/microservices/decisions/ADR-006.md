# ADR-006: Synchronous communication

## Status

Proposed

## Context

Some immediate deterministic calls require responses.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.
Strategy, Risk, and Market Data boundaries are currently in-process, proving typed seams before any synchronous network call.

## Decision

Use typed HTTP/existing RPC with timeout, correlation, auth, metrics, bounded idempotent retries.

## Alternatives considered

Unbounded calls; broker for request/response.

## Consequences

Explicit failures.

## Risks

Latency/fan-out.

## Rollback strategy

Legacy adapter.

## Approval required

Approve before remote calls.

Milestone note: Backtest execution shares an in-process adapter; no new synchronous network dependency was introduced. Status remains Proposed.
