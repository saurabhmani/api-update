# ADR-010: Scheduler ownership

## Status

Proposed

## Context

Multiple process modes can register jobs.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.
Scheduler characterization verifies `server.js` disables the in-process scheduler and the Backtest service skeleton cannot claim jobs.

## Decision

Require owner flag, durable lock/claim, old-off/new-on sequence, owner metrics, rollback.

## Alternatives considered

Run both; rely on timing.

## Consequences

Prevents duplicates.

## Risks

Flag/lock defects.

## Rollback strategy

Re-enable one legacy owner.

## Approval required

Approve each job move.

Milestone note: only Backtest queue-drain ownership is configurable. The monolith is the default and all other scheduled jobs remain unchanged. Status remains Proposed.
