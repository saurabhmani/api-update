# ADR-013: Risk fail-closed behavior

## Status

Proposed

## Context

Risk is mandatory for trade approval.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.
`@risk-engine` delegates by function identity to the existing Phase 3 risk, portfolio-fit, and execution-readiness implementations; the failure policy is versioned as preserving legacy fail-closed gates.

## Decision

Remote risk failure must not approve a trade; preserve Phase 3 rejection semantics.

## Alternatives considered

Fail open; informational risk.

## Consequences

Safety.

## Risks

Availability impact.

## Rollback strategy

Use approved local legacy path only before cutover.

## Approval required

Business/risk approval.
