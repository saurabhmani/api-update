# ADR-004: Strangler adapter pattern

## Status

Proposed

## Context

Capabilities need reversible routing.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.

## Decision

Use interface plus legacy/remote adapters and legacy-default flags; never fallback after ambiguous writes.

## Alternatives considered

Direct Nginx routing; big-bang replacement.

## Consequences

Canary and rollback.

## Risks

Adapter complexity.

## Rollback strategy

Select legacy mode.

## Approval required

Approve per capability.
