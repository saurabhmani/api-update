# ADR-011: Backtest processing ownership

## Status

Proposed

## Context

Scheduler drains a MySQL queue; no separate service exists.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.
`backtestQueue.ts` has a queued-only atomic claim. The proposed service defaults to monolith ownership and has no queue adapter or claim loop.

## Decision

Harden claims first; then allow exactly one monolith or service processor.

## Alternatives considered

Broker first; concurrent processors.

## Consequences

Reversible extraction.

## Risks

Stale/duplicate jobs.

## Rollback strategy

Set monolith owner.

## Approval required

Approve service enablement.

Milestone note: the transitional service requires explicit service ownership and enablement; no production topology was changed. Status remains Proposed.
