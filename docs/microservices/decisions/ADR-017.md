# ADR-017: Lease-based MySQL Backtest queue claiming

- Status: Proposed
- Date: 2026-08-03

## Decision

Use additive fields on authoritative MySQL `backtest_runs` and conditional updates for atomic claims. Claims record stable processor identity, increment attempts, and establish renewable leases. Final transitions verify ownership. Expired leases requeue only while attempts remain; exhausted work becomes `dead`.

## Consequences

This avoids version-specific locking SQL and introduces no broker. One validated ownership setting prevents split-brain; monolith remains the default and the worker remains disabled pending approval.
