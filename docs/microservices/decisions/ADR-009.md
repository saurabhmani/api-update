# ADR-009: Table ownership

## Status

Proposed

## Context

Most domains share MySQL.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.
The current Risk/Market facades and Backtest skeleton add no persistence and leave MySQL table access unchanged.

## Decision

Assign one logical owner; document temporary reads; prohibit new cross-service writes.

## Alternatives considered

Shared writes; immediate DB-per-service.

## Consequences

Incremental ownership.

## Risks

Legacy coupling remains.

## Rollback strategy

Keep current access.

## Approval required

Approve each transfer.

Milestone note: MySQL remains authoritative for all Backtest queue and result tables; no table ownership transferred. Status remains Proposed.
