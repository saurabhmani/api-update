# ADR-002: Strategy Engine package boundary

## Status

Proposed

## Context

Strategy evaluation is inline and directly imported.

## Evidence

See current-state verification, bounded-context map, ownership maps, and repository paths cited there.

## Decision

Expose the existing implementation through `@strategy-engine` and stable contracts, with no network or data move.

## Alternatives considered

Immediate service extraction; wholesale code move.

## Consequences

Reversible seam with unchanged behavior.

## Risks

Facade may initially depend on monolith internals.

## Rollback strategy

Revert consumer imports.

## Approval required

Review milestone tests and surface.
