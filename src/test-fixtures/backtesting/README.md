# Q365 deterministic Backtest canary fixture

Version 2.0.0 is repository-owned, deterministic synthetic market-shaped data generated by `scripts/generateBacktestFixture.ts`. It contains 280 weekday daily bars for an accepted-path symbol, a liquidity-rejection symbol, and a benchmark. It is not historical exchange truth and must not be used to assess profitability or market quality.

The generator fixes its seed and timestamps, performs no network access, and writes canonical JSON plus SHA-256 hashes. `npm run backtest:fixture:generated` proves committed output matches the generator; `npm run backtest:fixture:verify` separately checks content, manifest, hashes, schema, static runner suitability, and expected-path shape. Static suitability does not count as real-runner evidence.

Use only for processor parity, isolated staging preflight, canary baseline, and rollback verification. It contains no production/customer data and has no Redis, production-MySQL, wall-clock, live-provider, or uncontrolled-randomness dependency.
